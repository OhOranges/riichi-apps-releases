# 日麻计算器

一台手机记录四个人分数的立直麻将计算器。无账号、无广告，仅检查更新时联网。

当前鸿蒙版支持使用 schema 1 JSON 与 Android 互迁牌谱。

## 功能

- 东风战（东一至东四）或半庄（东一至南四），可设置四个名字与起家。
- 四家 25,000 点起始，自动更新场风、庄家、自风、本场、立直供托与排名。
- 记录立直、自摸、荣和、双响／三响、荒牌流局、不听罚符、途中流局、流局满贯、包牌责任与手动修正。
- 点选真实牌面图案，选择完整和牌手牌、副露、和牌张与指示牌，自动枚举拆解，选取得分最高的组合。识别通常役种、役满及双倍役满，显示番符和支付明细。
- 和牌结算可选图选牌型算分或手动输入支付点数；多人荣和可混用两种方式。先预览四家分差，再确认入账，自动加入本场与供托。
- 离线规则与番型浏览：15 章线下流程、雀魂四人场番型、搜索与筛选，不含古役。
- 每步自动保存；可以撤销、暂停后继续、管理多场对局、导出／导入 JSON 备份。


## 使用步骤

1. 「对局」→「开始新的对局」，选择东风／半庄、填写四人名字并指定起家。
2. 在立直宣言牌通过后点该玩家「立直」，扣除 1,000 点入供托。若被这张宣言牌荣和，先记录和牌，不能先接受立直。
3. 点击「对局 → 和牌结算」，选择「输入牌型算分」或「手动输入分数」。牌型方式点选手牌与条件，计算后加入结算；手动方式填写不含本场与供托的支付点数。多人荣和点「再加入一家」再次选择方式，统一选放铳者并一次结算。
4. 流局选择听牌玩家；已立直者固定为听牌。途中流局、流局满贯与线下犯规有单独入口。
5. 「指南」查阅洗牌配牌、吃碰杠、立直、振听、和牌／流局检查、收尾，以及不含古役的番型图鉴。
6. 「牌谱」查看每次分差及和牌输入，切换历史对局可继续记分。「设置」中导入／导出全部记录。

### 手动和牌结算

荣和填放铳者支付点数；庄家自摸填每位闲家支付点数；闲家自摸分别填庄家与每位其他闲家支付点数。金额为 100–1,000,000 的百点整数，不含本场与供托，APP 会自动补齐并预览最终四家变化；超出对局合法持点范围不能入账。手动输入不验证牌型与役种，有大三元／大四喜包牌时请用牌型算分并指定责任者。

### 点选牌面

手牌、和牌张、吃碰杠、宝牌和里宝牌指示牌全部点击麻将牌图案选择，无需输入文字或牌型代码。

1. 点击手牌区域「选牌」，切换万子、筒子、索子、字牌，点击图案连续添加。
2. 点击已选的牌即可删除；同一种牌最多四张，赤五每种花色一张，用完的牌自动变灰。
3. 和牌张直接从已选手牌中选取，不会多加一张。若删除对应的手牌，和牌张也会清除。
4. 添加或修改副露时直接点牌。三张顺子判为吃，三张同牌判为碰，四张同牌判为明杠，勾选「暗杠」可改为暗杠。点「完成」才保存。
5. 宝牌框点选**翻开的指示牌**，例如选四万，程序会自动把五万作为宝牌。赤五直接选择全红色图案的牌面。

## 规则范围

雀魂四人段位场官方规则为基础。多人荣和的本场与供托均为上家优先，包牌本场由责任者支付，天和自动选择最高得分和牌张。朋友场可配置的特殊规则、地区役、三人麻将、雀魂段位分没有纳入本应用。

本工具计算已经成立的和牌，不模拟牌山、摸打或自动识别照片。振听、最后一张牌、一发是否被鸣牌打断、包牌发生者和流局满贯成立情况由用户现场确认。

## 数据与隐私

安卓使用私有 SharedPreferences 保存完整对局 JSON，并同步确认保存是否成功。浏览器预览使用 localStorage。每条历史保留操作前后快照，备份导入检查点数总和、四家、局数、历史连续性与分差。导入前显示覆盖数量并请求用户确认；历史含同一 ID 时以导入版本覆盖，其余合并，最多保存 200 场。

应用仅申请 INTERNET 用于读取公开的 GitHub 更新版本文件，不上传对局记录，不申请通讯录、相机或广泛文件访问权限。文件备份通过 Android 系统文件选择器完成。卸载或清除应用数据会删除本机记录，请先导出 JSON。
